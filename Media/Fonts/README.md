# RQE bundled fonts

RQE bundles the following font families for the Font Settings picker:

- Abel
- Atomic Age
- Barlow
- Bebas Neue
- Bree Serif
- Crimson Text
- DM Serif Display
- Lobster
- Patua One
- Righteous

Each family is distributed with the `OFL.txt` file supplied by its source in
the Google Fonts repository.  The font files are used only by RQE and are not
registered as replacements for WoW's global fonts.
